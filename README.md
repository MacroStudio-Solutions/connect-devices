# connect-devices

Release channel do runtime `connect-devices` — hub local de dispositivos do
Studio (impressoras do SO primeiro, via provider SDK).

A fonte canônica vive no monorepo do Studio Pro, em `extensions/connect-devices`.
Este repositório publica apenas os binários por plataforma referenciados pelo
manifest do pack (`releases/download/v<version>/...`), com sha256 verificado na
instalação.

Contrato de inventário: `bridge-contract/v1`.
